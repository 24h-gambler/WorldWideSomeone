# WorldWideSomeone — 설계 문서 v4

> 전 세계 누군가에게 편지를 날리고, 머리 위를 지나는 편지를 잡거나 엿보고 끌어오고, **내 편지에 답장이 돌아와야(왕복)** 친구가 되어 실시간으로 대화하는 앱.
> **"썸원코인을 쓰거나, 친구를 많이 만들거나"** 로 성장하는 게임. 비회원으로 시작하고, 보내기·좋아요 순간에만 가입. 가격·한도의 계산 근거는 [`ECONOMY.md`](ECONOMY.md), 대규모 파이프라인은 [`SCALE.md`](SCALE.md).

## 0. 하나의 흐름 (반드시 유지되는 체계)

```
[비회원] 환영 → 위치 → 지구 (투어 5단계) ──▶ 둘러보기·잡기·엿보기 가능 ──▶ 보내기 / 좋아요 / 댓글 / 채팅 / 결제 순간에만 SNS 가입 시트
① 쓰기(해금 배달원 or SC 대여) ──▶ ② 배달원이 들고 감(실시간 이동 · 도착 시간은 비공개, 속도·거리만) ──▶ ③ 누군가의 머리 위 ──▶ 알림
                                                                                                             │
        ┌──────────────────────── 잡기 ◀───────────────────────────────────────────────────────────────────┤
        │                        🔍 엿보기(SC 한도) → 🧲 끌어오기(편지당 1회) · 🧭 경로(1·2·3) · 🐌 달팽이 · 🌊 침수(몇 시간, 주인이 SC 로 구조) · 🚀 우주
        │                           └─ 발신자의 🛡️ 방어권이 튕겨냄 · 착륙한 편지는 남에게 보이지 않음(근처 사람만 집어감)
        ▼
④ 읽기(보낸 사람 실제 프로필 · 이미지 공유) ──▶ ⑤ 답장(상대 배달원 — 느릴 수 있음) ──▶ ⑥ 받는 쪽은 속도·거리만 보고 기다리거나 SC 로 가속(4배/1분)
                                                                                                          │
                                                                                 ⑦ 도착 → 프로필 보고 수락 ──▶ 친구 + 지연 없는 실시간 채팅(50km 원)
                                                       친구 수 ↑ ──▶ 배달원 영구 해금 · 5명마다 방어권 ──▶ ①
   커뮤니티 ⚡ 직행 편지(300 SC) ──▶ 그 사람에게 무조건 도착(통과·장난 없음) · 답장은 상대의 마음 · 환불 없음
```

- **친구는 왕복이 끝나야**: 내 편지 → 상대 답장 → 도착 → 수락. 두 통이면 충분하고, 딜레이가 재미다. 유료 유저는 자기 배달원이 빠르지만 **돌아오는 답장은 상대 배달원**이므로 SC 로 가속을 산다.
- **도착 시간은 어디에도 표시하지 않는다**(체류 유도). 보이는 것은 현재 속도(km/h)와 나와의 거리(km), 진행 바.
- **오는 동안 프로필은 미리보기만**(아바타·닉네임·소개) — 도착해야 프로필 화면으로 들어갈 수 있다.
- **원화는 상점의 코인 팩·플랜에서만**. 그 밖의 모든 가격은 썸원코인(SC).
- **SNS 에는 받은 편지 수**만 보인다(보낸 수는 표시하지 않음).
- 위치는 친구에게 **50km 반경 원**, 서버에는 geohash 셀만.

## 2. 배달원 카탈로그 — 사람부터, 느린 것에서 빠른 것으로 (43종)

친구 수로 해금(플러스 −4, 프로 −10). 가족 칩(사람·육상·새·동물·해상·항공·우주·전설)으로 고른다. 벌칙 🐌 달팽이는 5분(실서비스 30분)만 ×0.1.

| 가족 | 배달원 (해금 친구 수 · km/h) | 특성 |
|---|---|---|
| 사람 | 걷는 배달원(0 · 5) · 조깅 배달원(1 · 9) · 스프린터(2 · 16) | 잡기 창 넓음, 표류 |
| 육상 | 킥보드(2 · 15) · 자전거(3 · 25) · 스쿠터(11 · 60) · 경차(13 · 90) · 버스(16 · 80, 잡기 창 +30%) · 세단(19 · 120) · 트럭(21 · 95, 🛡️ 내장) · 기차(23 · 160) · **스포츠카(25 · 260, 잡기 창 −30%)** · 고속열차(30 · 300) · 자기부상열차(36 · 430) | |
| 새 | 비둘기(4 · 60) · 갈매기(5 · 70, 바다 위 +20%) · 기러기(7 · 80) · 두루미(9 · 85) · 매(12 · 130, 잡기 창 −20%) · 독수리(15 · 150, 🐌 면역) · 앨버트로스(18 · 140, 직진 장거리) | |
| 동물 | 말(6 · 45) · 낙타(8 · 40, 바다 1시간 부상) · 돌고래(10 · 55, 🌊 면역) · 치타(14 · 110) | |
| 해상 | 요트(5 · 20, 바다 1시간 부상) · 스피드보트(12 · 75) · 크루즈(17 · 45, 🛡️ 내장 · 잡기 창 +40%) · 잠수함(22 · 40, 🌊·🔍 면역) · 호버크래프트(27 · 90) | |
| 항공 | 열기구(8 · 30, 잡기 창 +60%) · 패러글라이더(10 · 40) · 헬리콥터(24 · 250) · 프로펠러기(28 · 350) · 여객기(40 · 900) · 전투기(50 · 2,000, 🐌 면역) · 콩코드(55 · 2,200) | |
| 우주 | 로켓(60 · 6,000) · 🛰️ 궤도 위성(상점/프로 · 28,000, 3바퀴 · 잡기 창 ×1.5) · 🛸 UFO(상점/프로 · 12,000, 지그재그 · 잡기 창 ×2.2) | |
| 전설 | 마법 양탄자(상점 · 800, 🔍 면역) · 유니콘(시즌 이벤트 · 500) · 드래곤(80명 또는 프로 · 2,500, 전체 면역) | |

체감 시간 = 속도 × 배속(로컬 시뮬 기본 240, 서버 60). 걷기 5km/h × 240 → 서울→도쿄 약 1시간(앱 내).
지구 위에서 배달원은 **매 틱(1초)** 위치가 갱신되고 진행 방향으로 기울어지며(서쪽이면 좌우 반전), 달팽이가 붙으면 🐌, 바다에 빠지면 🌊 상태 아이콘으로 바뀐다.

| 5,500 | 5,500 | +46% | ₩49,000 | ₩8.9 |

## 7. 데이터 모델 (Supabase / Postgres) — DB 가 필요한 이유

편지는 **내 폰이 꺼져 있어도** 지구 위를 움직이고, 다른 사람 머리 위를 지나가며, 잡히고 끌려간다. 세계 상태는 서버 DB 에 있고 클라이언트는 구독한다. 환경변수가 없으면 로컬 봇 시뮬로 동일 UX.

```
users            공개 프로필 + 게임 상태(coins·inventory·quota·stats{received…}·friend_ids·revealed_ids·plan) — 게임 필드는 트리거가 클라이언트 수정을 되돌린다
users_private    lat·lng·geohash6/4·push_token·조용한 시간·통과 푸시 카운터 — 아무도 읽지 못함(서버만)
letters          본문 · kind(letter|reply) · direct · rented · boost · status · participants[] · cells4[](다음 60초 지날 셀)
letters_public   하늘 위 표시용 뷰(본문·목적지 도시 없음)
passbys          (user, letter) unique · expires_at · can_catch · peeked · resolved
chats · messages · chat_reads     멤버만 · 메시지 insert 는 본인만 · 트리거가 푸시 큐에 넣음
posts · posts_public(좌표 숨김) · post_likes · comments
notifications · push_queue(우선순위·kind) · purchases(트랜잭션 id unique) · coin_ledger(잔액) · events(트래킹, anon insert)
```

Edge Functions: `tick-world`(매 분: 재부상·도착·만료·셀 예측·통과 판정·알림 큐), `push-dispatch`(30초: 한도·조용한 시간·묶음·Expo 배치), `send-letter`(한도·대여·직행·방어권), `catch-letter`, `redirect-letter`(peek/pull/reroute/snail/sunk/space), `rescue-letter`, `approve-reply`, `boost-reply`, `set-location`(분당 1회·geohash), `register-push`, `publish-post`, `track-events`, `purchase-webhook`(RevenueCat). 규칙과 상한은 [`SCALE.md`](SCALE.md).

## 8. 로컬 시뮬레이션 규칙 (서버 없이 전체 루프 체험)

- 봇 60명. 온보딩 시 편지 10통(3통은 1~4분 내 내 상공 통과하도록 목적지 보정), 이후 25~60초마다 1통(45%는 조준).
- 통과 판정: 매초, 이전 틱~현재 사이 경로 샘플의 최소 거리 ≤ 150km. 잡기 창 75초 × 배달원 계수. 궤적은 40km 마다 1점(최대 240점) 저장.
- 내 편지: 목적지 근처 조건 일치 봇이 착륙 후 15~60초에 잡음(90%) → 10~40초 후 답장(봇의 해금 수준 배달원 — 느릴 수 있음, 받는 내가 SC 로 가속) → 도착하면 내가 수락 → 친구.
- 내 답장: 도착 10~40초 후 봇이 90% 수락 → 친구 · 인사 · 채팅 응답 2.5~9초.
- 직행 편지: 도착 10~40초 후 봇이 80% 답장(환불 없음).
- 장난: 내 편지 15% 확률로 비행 중 봇이 경로변경/달팽이/반환/바다/우주/끌어오기. 방어권 있으면 방어 이벤트. 바다는 배속 반영해 3시간/(배속/60), 최소 90초 후 재부상.
- 엽서: 시드 + 90~240초마다 1개, 댓글 봇, 내 엽서는 20~90초 후 좋아요.

## 9. UI 원칙 (v4)

1. 인스타의 문법 그대로: 헤더 52px, 얇은 구분선, 블루 CTA, 회색 보조, 밑줄 탭, 링 아바타. 다크는 인스타 다크 팔레트로 토큰만 바꾼다(`useColors`).
2. 지구는 젠리처럼 밝고 둥글다. 육지 윤곽은 0.6px 반투명으로 낮추고, 버블만 눈에 띄게. 배달원은 이모지가 아닌 **직접 그린 아이콘**이 매초 움직인다.
3. 경로는 비밀. 탭한 편지에만 지나온 길(실선)·남은 길(점선)·사건 표시(🌊 추락 · 🧭 변경 · 🧲 끌림).
4. 모든 상태 전환은 한 줄 설명을 붙인다("확정하면 친구가 되고 실시간 채팅이 시작돼요").
5. 익명은 커뮤니티에서만(???·거리). 편지를 주고받은 사람에게는 진짜 프로필.

6. 도착 시간은 절대 보여주지 않는다. 속도와 거리만.
7. 비회원도 전부 볼 수 있다. 가입은 행동(보내기·좋아요·댓글·채팅·결제)의 순간에만, 시트 한 장으로.
