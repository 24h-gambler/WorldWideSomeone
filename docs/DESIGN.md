# WorldWideSomeone — 설계 문서 v3

> 전 세계 누군가에게 편지를 날리고, 머리 위를 지나는 편지를 잡거나 엿보고 끌어오고, **왕복 편지가 끝나야** 친구가 되어 실시간으로 대화하는 앱.
> **"결제를 많이 하거나, 친구를 많이 만들거나"** 로 성장하는 게임. 가격·한도의 계산 근거는 [`ECONOMY.md`](ECONOMY.md).

## 0. 하나의 흐름 (반드시 유지되는 체계)

```
① 쓰기 ──▶ ② 배달원이 들고 감(사람 → 새·동물·차·기차·배·비행기·로켓, 실시간으로 지구 위를 이동) ──▶ ③ 누군가의 머리 위 ──▶ 알림
                                                                                                          │
        ┌────────────────────────── 잡기 ◀────────────────────────────────────────────────────────────────┤
        │                                 🔍 엿보기(내용 미리보기, 유료 한도) → 🧲 끌어오기(내 위치로, 편지당 1회)  ─┤
        │                                 🧭 경로 바꾸기(경유지 1·2·3) · 🐌 달팽이 · ↩️ 되돌리기 · 🌊 바다 · 🚀 우주 ─┘
        │                                    └─ 발신자의 🛡️ 방어권이 튕겨냄 · 🌊 바다는 몇 시간 정지, 주인이 🛟 건져내면 재개
        ▼
④ 읽기(보낸 사람의 실제 프로필 공개 · 이미지로 공유) ──▶ ⑤ 답장 편지 ──▶ ⑥ 상대 우편함 ──▶ ⑦ 수락 → 수락 편지 출발 ──▶ ⑧ 도착 → 확정
                                                                                                                                │
                                                                                            친구 + 지연 없는 실시간 채팅 ◀───────┘
                                                                친구 수 ↑ ──▶ 더 빠른 배달원 해금 · 5명마다 방어권 ──▶ ①
   커뮤니티 ⚡ 즉시 친구(결제) ──▶ 왕복 없이 요청 → 상대 수락 시 바로 친구(거절 시 환불)
```

- **친구는 왕복이 끝나야** 된다: 편지 → 답장 → 수락 편지 → 확정. 양쪽 모두 상대의 편지를 한 번씩 읽고 판단한다. 확정 전 채팅은 잠김.
  - 이탈을 줄이기 위해 **수락 편지의 배달**은 플랜별로 다르다: 무료 = 현재 최고 배달원, 플러스 = 보유 중 가장 빠른 배달원, 프로 = 즉시 전달. 마지막 확정은 탭 한 번.
- **편지를 받으면 보낸 사람이 공개**된다(닉네임·소개·태그·엽서). ???는 커뮤니티에서만.
- **경로는 숨김**: 목적지는 비밀. 지구에서 배달원을 탭한 편지만 지나온 길(실선 · 바다 추락·경로 변경 지점 표시)과 남은 길(점선)이 보인다.
- 위치는 친구에게 **50km 반경**, 서버에는 **10km 격자**(통과 판정용)만 저장.

## 2. 배달원 카탈로그 — 사람부터, 느린 것에서 빠른 것으로 (43종)

친구 수로 해금(플러스 −4, 프로 −10). 가족 칩(사람·육상·새·동물·해상·항공·우주·전설)으로 고른다. 벌칙 🐌 달팽이는 5분(실서비스 30분)만 ×0.1.

| 가족 | 배달원 (해금 친구 수 · km/h) | 특성 |
|---|---|---|
| 사람 | 걷는 배달원(0 · 5) · 조깅 배달원(1 · 9) · 스프린터(2 · 16) | 잡기 창 넓음, 표류 |
| 육상 | 킥보드(2 · 15) · 자전거(3 · 25) · 스쿠터(11 · 60) · 경차(13 · 90) · 버스(16 · 80, 잡기 창 +30%) · 세단(19 · 120) · 트럭(21 · 95, 🛡️ 내장) · 기차(23 · 160) · **스포츠카(25 · 260, 잡기 창 −30%)** · 고속열차(30 · 300) · 자기부상열차(36 · 430) | |
| 새 | 비둘기(4 · 60) · 갈매기(5 · 70, 바다 위 +20%) · 기러기(7 · 80) · 두루미(9 · 85) · 매(12 · 130, 잡기 창 −20%) · 독수리(15 · 150, 🐌 면역) · 앨버트로스(18 · 140, 직진 장거리) | |
| 동물 | 말(6 · 45) · 낙타(8 · 40, 바다 1시간 부상) · 돌고래(10 · 55, 🌊 면역) · 치타(14 · 110) | |
| 해상 | 요트(5 · 20, 바다 1시간 부상) · 스피드보트(12 · 75) · 크루즈(17 · 45, 🛡️ 내장 · 잡기 창 +40%) · 잠수함(22 · 40, 🌊·🔍 면역) · 호버크래프트(27 · 90) | |
| 항공 | 열기구(8 · 30, 잡기 창 +60%) · 패러글라이더(10 · 40) · 헬리콥터(24 · 250) · 프로펠러기(28 · 350) · 여객기(40 · 900) · 전투기(50 · 2,000, 🐌 면역) · 콩코드(55 · 2,200) | |
| 우주 | 로켓(60 · 6,000) · 🛰️ 궤도 위성(상점/프로 · 28,000, 3바퀴 · 잡기 창 ×1.5) · 🛸 UFO(상점/프로 · 12,000, 지그재그 · 잡기 창 ×2.2) | |
| 전설 | 마법 양탄자(상점 · 800, 🔍 면역) · 유니콘(시즌 이벤트 · 500) · 드래곤(80명 또는 프로 · 2,500, 전체 면역) | |

체감 시간 = 속도 × 배속(로컬 시뮬 기본 240, 서버 60). 걷기 5km/h × 240 → 서울→도쿄 약 1시간(앱 내).
지구 위에서 배달원은 **매 틱(1초)** 위치가 갱신되고 진행 방향으로 기울어지며(서쪽이면 좌우 반전), 달팽이가 붙으면 🐌, 바다에 빠지면 🌊 상태 아이콘으로 바뀐다.

## 7. 데이터 모델 (Firestore) — DB 가 필요한 이유

편지는 **내 폰이 꺼져 있어도** 지구 위를 움직이고, 다른 사람 머리 위를 지나가며, 잡히고 끌려간다. 그래서 세계 상태(편지 위치·통과·친구·채팅·결제 지급)는 서버 DB 에 있어야 하고, 클라이언트는 그것을 구독한다. Firebase 환경변수가 없으면 로컬 봇 시뮬로 동일 UX.

```
users/{uid}            공개 프로필 + 게임 상태(coins·inventory{shield,peek,pull,instant,ufo,orbit,carpet}·quota·plan·friendIds·revealedIds·stamps) — 게임 필드는 서버만 수정
users_private/{uid}    lat·lng·geohash(10km 격자)·pushToken — 본인만 쓰고 아무도 읽지 못함(서버만)
users/{uid}/passbys/{letterId}   통과 이벤트(at·expiresAt·canCatch·peeked·resolved)
users/{uid}/notifications/{id}
```

## 8. 로컬 시뮬레이션 규칙 (서버 없이 전체 루프 체험)

- 봇 60명. 온보딩 시 편지 10통(3통은 1~4분 내 내 상공 통과하도록 목적지 보정), 이후 25~60초마다 1통(45%는 조준).
- 통과 판정: 매초, 이전 틱~현재 사이 경로 샘플의 최소 거리 ≤ 150km. 잡기 창 75초 × 배달원 계수. 궤적은 40km 마다 1점(최대 240점) 저장.
- 내 편지: 목적지 근처 조건 일치 봇이 착륙 후 15~60초에 잡음(90%) → 10~40초 후 답장 편지 → 도착하면 내가 수락 → 수락 편지 도착 10~40초 후 봇이 확정.
- 내 답장: 도착 10~40초 후 봇이 90% 수락 → 수락 편지가 내게 옴(세단/고속열차/여객기) → 내가 확정 → 친구 · 인사 · 채팅 응답 2.5~9초.
- 장난: 내 편지 15% 확률로 비행 중 봇이 경로변경/달팽이/반환/바다/우주/끌어오기. 방어권 있으면 방어 이벤트. 바다는 배속 반영해 3시간/(배속/60), 최소 90초 후 재부상.
- ⚡ 즉시 친구: 8~30초 후 80% 수락, 아니면 환불. 엽서: 시드 + 90~240초마다 1개, 댓글 봇, 내 엽서는 20~90초 후 좋아요.
