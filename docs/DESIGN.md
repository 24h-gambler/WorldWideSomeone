# WorldWideSomeone — 설계 문서 v2

> 전 세계 누군가에게 편지를 날리고, 머리 위를 지나는 편지를 잡고, 답장을 승인해 실시간 친구가 되는 앱.
> **"결제를 많이 하거나, 친구를 많이 만들거나"** 로 성장하는 게임.

---

## 0. 하나의 흐름 (반드시 유지되는 체계)

```
① 쓰기 ──▶ ② 배달원이 들고 감(느림→빠름) ──▶ ③ 누군가의 머리 위 ──▶ 알림
                                                                   │
        ┌──────────────────── 잡기 ◀──────────────────────────────┤
        │                                                          └─ 장난: 경로 바꾸기(경유지 1·2·3) / 달팽이 / 되돌리기 / 바다 / 우주
        ▼                                                             └─ 발신자의 🛡️ 방어권이 튕겨냄
④ 읽기 ──▶ ⑤ 답장 편지(직행) ──▶ ⑥ 발신자 우편함 도착 ──▶ ⑦ 승인 ──▶ ⑧ 친구 + 지연 없는 실시간 채팅
                                                                                       │
                                                       친구 수 ↑ ──▶ 더 빠른 배달원 해금 · 5명마다 방어권 ──▶ ①
```

- **승인 전에는 편지로만** 대화한다(채팅 화면은 잠김). 승인 후에만 실시간 채팅.
- 커뮤니티는 모두 **???** 로 보이고 태그·컨택 가능성만 공개. 친구가 되면 닉네임·소개가 열린다.
- 위치는 친구에게 **50km 반경**, 서버에는 **10km 격자**(통과 판정용)만 저장.

## 2. 배달원(운송수단) 진행 — 사람부터, 느린 것에서 빠른 것으로

| 단계 | 친구 | 배달원 | 속도(시뮬 km/h) | 특징 |
|---|---|---|---|---|
| 벌칙 | — | 🐌 달팽이 | ×0.1 | 지나가던 사람이 붙임. **5분(실서비스 30분)** 만 느려지고 원래 배달원으로 복귀 |
| 0 | 0 | 🚶 걷는 배달원 | 5 | 시작. 조금 표류 |
| 1 | 2 | 🏃 조깅 배달원 | 10 | |
| 2 | 5 | 🏃‍♀️ 스프린터 | 18 | 사람 중 최고 속도 |
| 3 | 8 | 🚴 자전거 | 25 | |
| 4 | 12 | 🏇 말 | 45 | |
| 5 | 16 | 🛵 스쿠터 | 70 | |
| 6 | 22 | 🚗 자동차 | 120 | |
| 7 | 30 | 🚄 고속열차 | 300 | |
| 8 | 40 | ✈️ 비행기 | 900 | |
| 9 | 55 | 🚀 로켓 | 6,000 | |
| ★ | 80 또는 프로 | 🐉 드래곤 | 2,500 | 장난 면역 |
| 💳 | 상점/프로 | 🛸 UFO | 12,000 | 지그재그 · 잡기 창 2.2배 |

걷기 5km/h × 240 → 서울→도쿄 약 1시간(앱 내), 서버 배속 60 → 약 4시간.

## 3. 장난과 방어

| 지나가던 사람의 선택 | 효과 | 방어권 |
|---|---|---|
| 🧭 경로 바꾸기 | 현재 위치에서 **내가 찍은 경유지**(무료 1 · 플러스 2 · 프로 3)를 거쳐 원래 목적지로 | 막힘 |
| 🐌 달팽이 붙이기 | 5분 동안 10배 느림 | 막힘 |
| ↩️ 되돌리기 | 발신자에게 반환 | 막힘 |
| 🌊 바다에 · 🚀 우주로 | 편지 소멸 | 막힘 |

방어권 획득: **친구 5명마다 +1**, 플러스 매월 5, 프로 매월 15, 상점 5개 ₩2,900. 편지당 1개 장착, 1회 방어 후 소모.

## 4. 요금제

| | 무료 | 플러스 ₩4,900/월 | 프로 ₩9,900/월 |
|---|---|---|---|
| 경로 변경 경유지 | 1 | 2 | 3 |
| 매월 방어권 | 친구 5명마다 | 5 | 15 |
| UFO / 위성 | 상점 | 상점 | 3 / 1 매월 |
| 해금 요구 친구 수 | 기본 | −4 | −10 (드래곤 즉시) |
| 하루 편지 | 5 | 20 | 무제한 |
| 컨택 가능성 | 기본 | +8% | +15% · 우선 노출 · ★ 뱃지 |

소모품: 방어권 5개 ₩2,900 · UFO ₩1,900 · 위성 ₩3,900 · 코인 300 ₩3,900 · 코인 1,000 ₩9,900. 코인(소프트 재화)은 잡기 +10 · 친구 +25 · 잡힘 +5 · 좋아요 +1 · 발송 +2 로 쌓이고, 소모품은 코인으로도 살 수 있다(결제 or 플레이).

## 6. 데이터 모델 (Firestore)

```
users/{uid}            공개 프로필 + 게임 상태(coins·inventory·plan·friendIds·stamps·shieldMilestone) — 게임 필드는 서버만 수정
users_private/{uid}    lat·lng·geohash(10km 격자)·pushToken — 본인만 쓰고 아무도 읽지 못함(서버만)
users/{uid}/passbys/{letterId}   통과 이벤트(at·expiresAt·canCatch·resolved)
users/{uid}/notifications/{id}
letters/{id}           본문 포함 · participants[]만 읽기 · 쓰기는 callable만
letters_public/{id}    하늘 위 표시용 요약(origin·destination·waypoints·vehicle·departedAt·arrivesAt·status·shield·penalty)
chats/{a_b}/messages   members[]만 · 생성은 본인 senderId 만
posts/{id}             엽서(likes·likedBy) · 좋아요는 callable
```

Cloud Functions (asia-northeast3): `tickWorld`(매 분: 도착·배달·만료·**통과 판정+푸시**), `sendLetter`, `catchLetter`, `redirectLetter`(경로/달팽이/반환/바다/우주 + 방어권), `approveReply`(친구·채팅방·마일스톤), `likePost`, `onMessageCreate`(채팅 푸시), `revenuecatWebhook`.

클라이언트 `src/services/`: `firebase`(초기화·익명 로그인) · `sync`(구독/콜러블) · `location`(권한·GPS·백그라운드 태스크) · `push`(권한·토큰·알림 탭 라우팅) · `purchases`(Mock/RevenueCat). Firebase 환경변수가 없으면 **로컬 봇 시뮬레이션**으로 동일 UX.

## 7. 로컬 시뮬레이션 규칙 (서버 없이 전체 루프 체험)

- 봇 60명. 온보딩 시 편지 10통(3통은 1~4분 내 내 상공 통과하도록 목적지 보정 `aimRouteAt`), 이후 25~60초마다 1통(45%는 조준).
- 통과 판정: 매초, 이전 틱~현재 사이 경로 샘플의 최소 거리 ≤ 150km. 잡기 창 75초 × 배달원 계수.
- 내 편지: 목적지 근처(2,500km) 조건 일치 봇이 착륙 후 15~60초에 잡음(90%) → 10~40초 후 답장 편지(친구 요청 포함) 발송 → 도착하면 내가 승인.
- 내 답장: 도착 10~40초 후 봇이 90% 승인 → 친구 · 인사 메시지 · 채팅 응답 2.5~9초.
- 장난: 내 편지 15% 확률로 비행 중 봇이 경로변경/달팽이/반환/바다/우주. 방어권 있으면 방어 이벤트.
- 엽서 피드: 시드 24개 + 90~240초마다 1개. 내 공개 엽서는 20~90초 후 좋아요.
