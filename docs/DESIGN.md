# WorldWideSomeone — 설계 문서

> 전 세계 누군가에게 편지를 날려 보내고, 내 머리 위를 지나가는 편지를 잡아 친구가 되는 앱.

---

## 0. 한 줄 정의와 핵심 루프

**"지구 위를 날아가는 편지"를 보내고 · 잡고 · 친구가 되는** 위치 기반 소셜 앱.

```
쓰기 ─▶ 날리기 ─▶ (지구를 가로질러 비행) ─▶ 누군가의 머리 위 ─▶ 알림
                                                              │
        친구 ◀─ 1:1 채팅 ◀─ 친구 요청 ◀─ 읽기 ◀─ 잡기 ◀──────┘
          │                                        (또는 경로 변경: 반환 / 바다 / 우주)
          ▼
   친구 수 ↑ ─▶ 운송수단 해금 ─▶ 더 멋진 편지 ─▶ 더 많은 잡힘
```

핵심 감정: **기대(비행 중) → 놀람(머리 위 알림) → 선택(잡을까, 튕겨낼까) → 연결(친구)**.

## 2. 기능 전수조사 (Feature Inventory)

### 2.1 편지 보내기 (Compose)
- [x] 텍스트(최대 500자) + 이미지 1장(선택)
- [x] 목적지: (a) 지구에서 직접 찍기 (b) 랜덤 (c) 유료: 경로 지정(경유지)
- [x] 운송수단 선택: 친구 수로 해금 (2.5)
- [x] 받는 사람 조건(선택): 분야 / 성별 / 직무 / 취미 → 조건이 맞는 사람만 잡을 수 있음
- [x] 컨택 가능성 %: 경로 주변 + 조건 일치 유저 수 기반으로 즉시 계산해 보여줌
- [x] 우표(스탬프) 붙이기: 출발 도시 스탬프 자동
- [x] 방어권(유료) 장착: 경로 변경 시도 1회 방어

### 2.2 비행 (Flight)
- [x] 대권(great-circle) 경로를 운송수단 속도로 이동
- [x] 지구 화면에서 실시간 관람: 아크 + 아이콘 + 진행률
- [x] 탭 → 상세 카드(출발/목적지/남은 시간/속도/누가 보냈는지는 ???)
- [x] 위성/UFO 등 특수 수단은 특수 궤적(궤도 반복, 지그재그)
- [x] 도착 후 착륙 상태: 목적지 50km 이내 유저에게 24h 동안 잡을 기회

### 2.3 머리 위 통과 · 알림 · 잡기 (Pass-by / Catch)
- [x] 내 위치 반경 150km 안으로 편지가 들어오면 **푸시 알림**("✈️ 종이비행기가 머리 위를 지나가요!")
- [x] 잡기 화면: 남은 시간 게이지(통과 소요 시간), 살짝 흔들리는 운송수단, "잡기" 버튼
- [x] 대안 액션(장난): **되돌려보내기**(발신자로 반환) / **바다에 빠뜨리기** / **우주로 쏘기**
- [x] 방어권이 장착된 편지는 장난이 튕겨나감(애니메이션 + 발신자에게 알림)
- [x] 조건 불일치 유저는 알림은 받되 "잡기"가 비활성(??? 조건의 편지를 구경만)

### 2.4 읽기 · 친구 요청 · 채팅 (Read / Friend / Chat)
- [x] 잡으면 봉투 개봉 애니메이션 → 텍스트/이미지 + 스탬프
- [x] **즉시 친구 요청** 버튼(1탭) → 상대에게 알림 → 수락 시 친구

## 5. 시뮬레이션 엔진 (오프라인 · 서버 없는 MVP)

MVP는 **완전 클라이언트 시뮬레이션**으로 전체 루프를 체험할 수 있게 한다(서버 도입 전에 재미 검증).

- **월드 클록**: 실시간 × `timeScale`(기본 120배). 종이비행기 300km/h → 10,000km 여정 ≈ 33시간(시뮬) ≈ 17분(실제). 개발자 모드에서 배속 조절/즉시 도착.
- **봇 유저 60명**: 전 세계 도시에 분포, 분야·취미 랜덤. 봇이 주기적으로 편지를 발송하며 일정 비율은 **의도적으로 사용자의 위치 근처를 통과**하도록 목적지를 잡는다(첫 통과 이벤트가 2~3분 내 발생하도록 튠).
- **통과 판정**: 매 초 비행 위치와 내 위치의 대권거리 ≤ 150km → 알림 1회 + 잡기 창(창 길이 = 300km / 속도, 최소 90초·시뮬 기준을 실시간으로 환산).
- **봇의 반응**: 내 편지는 경로/목적지 주변 봇이 확률적으로 잡음(도착 후 1~3분 내). 잡은 봇은 70% 확률로 친구 요청, 채팅은 템플릿 + 지연 응답.
- **장난 시뮬**: 봇이 낮은 확률(8%)로 내 편지에 장난 → 방어권 있으면 방어 성공 이벤트.
- **저장**: zustand + AsyncStorage. 재실행 시 `departedAt`/`arrivesAt`로 위치 재계산(끊김 없음).

서버 도입 시 교체 지점: `src/engine/sim.ts`의 봇 행동 → 서버 이벤트 스트림, `store` 액션 → API. 화면 코드는 그대로.

## 8. UI 원칙

1. **지구가 주인공**: 홈은 지구 하나. UI는 지구 가장자리에 살포시.
