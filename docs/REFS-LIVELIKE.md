# REFS-LIVELIKE — 제타 → LiveLike (사용자 지정)

기준: **제타** (repo README도 "제타의 검증된 채팅 UX 위에 삶을 올린 제품"이라 명시).
스푼 패턴은 Astream 담당 (`docs/REFS-ASTREAM.md`). 제타 공용 패턴은 `docs/REFS-BEFF.md` Z1–Z5도 함께 본다.

전수조사: App Store "스푼 : 라이브 & 팟노블"(Spoonlabs, ★3.4, 8.4천 리뷰) 실확인.
배포 사이트 주행(livelike-app.vercel.app): 카탈로그(7개 삶+예정 7종) → 개발자 삶 상세 진입 정상, 콘솔에러 0.
단 샌드박스에서 Supabase `ll_events` 호출 2건 터널 차단 — 내 서버망 문제로 보이며 실환경(CI·실기기)에서 재확인 필요.

## 스푼 → LiveLike 매핑

- **S1 라이브 카드 규격**: 썸네일 + LIVE 뱃지 + 청취자 수 + 제목 2줄 클램프 + DJ 아바타. 목록의 정보 밀도 기준.
- **S2 입장 테이크오버**: 방 입장 시 채팅 오버레이+리액션 바+기프트 버튼 1화면. "들어갔다" 느낌의 전환 애니메이션.
- **S3 리액션·기프트 레일**: 하단 고정 리액션 바, 기프트는 2탭(선택→확인) 오탭 방지.
- **S4 카테고리 레일 + 랭킹**: 가로 카테고리, 일간/주간 랭킹 탭. 탐색의 뼈대.
- **S5 크리에이터 진입**: "방송 켜기" 1탭 + 마이크 권한 프라이밍(스푼은 선택권한을 기능 시점에 요청 — WWS CLAUDE.md의 게이트 철학과 동일).
- **S6 미니 플레이어**: 오디오 전용 축소 바 + 잠금화면 컨트롤. 백그라운드 청취 전제.
- **S7 리뷰 교훈**: 스푼 저평점(3.4) 사유 — 사칭/분위기(닉네임 중복 허용), 과금 피로. LiveLike 설계에 반영: 닉네임 중복 정책 + 무료/유료 경계 명시.
