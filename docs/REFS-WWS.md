## 범프 → WWS 홈(지구)·친구

- **B1 친구 핀 상태 노출**: 범프는 핀에 배터리·동행·체류시간 표시. WWS 홈 지구의 친구 50km 원에 "상태 점" 추가 제안 — 예: 오는 편지 있음(파랑 점), 답장 대기(주황 점). 지도 가독성은 유지(점만).
- **B2 바텀시트 친구 리스트**: 범프는 지도+하단 친구 시트. WWS 홈 하단 "내 편지" 카드를 시트로 확장(드래그 3단) — 속도·거리·가속 버튼 한곳에.
- **B3 BUMP 제스처 모먼트**: 흔들면 합류 알림. WWS 잡기 성공 순간에 햅틱+풀스크린 테이크오버(지금은 카드 전환) — "잡았다" 쾌감을 스푼 LIVE 입장급으로.
- **B4 장소 발자취**: 방문지 자동 지도. WWS 프로필에 "편지가 닿은 나라" 발자취 지도(받은 편지 수와 연결, 보낸 수는 계속 비공개).
- **B5 권한 프라이밍 카피**: 범프식 "왜 필요한지 먼저 설명 → 시스템 다이얼로그". WWS 위치 화면 카피를 혜택형으로 ("편지가 머리 위를 지날 때 알려줘요").

## 인스타 → WWS 커뮤니티·채팅·상점·스토리

- **I1 스토리 링 상태**: 본 사람(회색)/안 본 사람(그라데이션) 링. WWS 국가 스토리에 그대로 — "내 나라"는 별도 고정.
- **I2 피드 카드 규격**: 아바타+이름+거리 1행, 더블탭 좋아요, 댓글 수 표기. WWS 커뮤니티 피드와 90% 일치 — 다른 10%(거리 표기 위치·좋아요 게이트 문구)만 맞추면 됨.
- **I3 DM 패턴**: 말풍선+읽음 표시+스와이프 답장+이모지 리액션. WWS 채팅에 읽음 표시 없음 → "읽음" 대신 "배달원이 도착" 메타포 유지하되 답장 스와이프는 도입 검토.
- **I4 결제 화면**: 인기 뱃지·비교표·첫달 강조 (WWS 상점은 인기 태그 있음 → 플랜 비교 3열표 제안).
- **I5 다크 토큰**: v3이 이미 인스타 다크 계열(#000/#FAFAFA) — 유지. 추가 작업 없음.
- **I6 스켈레톤 로딩**: 피드 진입 시 카드 스켈레톤 (현재 빈 상태 문구만) — 체감속도 개선.
