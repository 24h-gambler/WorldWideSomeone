## 2. 오류 · 잔오류

| 발견 | 조치 |
|---|---|
| 가입 직후 Supabase 동기화가 시작되지 않음(온보딩 시점에만 startSync) | **고침**: signedIn 변화 시 startSync |
| Supabase 모드에서 게임 액션(보내기·잡기·장난·수락·가속·구조·엽서·좋아요·댓글·위치)이 서버로 전송되지 않음 | **고침**: 스토어 `RemoteBridge` — 로컬 상태를 먼저 바꾸고 Edge Function 을 호출, 실패해도 UI 는 유지 |
| 통과 알림이 온 편지가 내 목록에 없으면 배너를 그릴 수 없음 | **고침**: 알림 수신 시 `letters_public` 에서 해당 편지를 가져옴 |
| 로컬 모드에서 분석 이벤트가 flush 때 버려짐 / 200건만 보관 | **고침**: 서버 없으면 1,000건 보관 |
| 자동 검증 32/32 · 콘솔 오류 0 | ✅ (`docs/VERIFICATION.md`) |

## 3. 규모 · 경제 상호관계

| 항목 | 판단 |
|---|---|
| 답장이 걷기(5km/h)면 10,000km 에 2,000시간 — 무료 유저끼리는 왕복이 몇 달 | **고침**: 답장 최소 자전거. 그래도 400시간(17일)이 될 수 있어 받는 쪽의 가속(80/200 SC)이 실제 수요가 된다. 더 줄이려면 하한을 세단(120km/h)으로 — 결정 필요 |
| 하루 무료 60 SC 상한 vs 보상(친구 25) | 하루 친구 2명이면 상한 도달. 상한 도달을 알리는 문구는 상점에만 있음 → 알림 추가 권장(미반영) |
| 직행 편지 300 SC 와 답장 가속 200 SC | 직행은 "도착 보장", 가속은 "기다림 단축"으로 역할이 겹치지 않음. 직행은 일일 편지 한도를 우회(유료라 의도) |
| 대여 40~400 SC vs 영구 해금 | 무료로 매일 대여 가능한 건 자전거(40)까지 → 유료 구간 유지. 단, 대여로 스포츠카(80)를 매일 쓰면 월 2,400 SC(₩24,000) — 친구 25명 해금과 비교해 결제 유인이 충분히 큼 |
| 플러스 매월 300 SC + 할인 20% | 가속 fast 64 SC × 4회 = 월 무료 수준. 플러스의 실질 가치는 엿보기·끌어오기 한도 → OK |
| 통과 판정 서버 부하 | 편지당 후보 조회 1회 + 사용자 배치 조회 1회로 줄임(**고침**: N+1 제거). 편지 3,000/분 초과 시 지역 샤딩(SCALE.md) |
| 트래킹 볼륨 | 사용자 10만 × 분당 2건 = 20만 행/분. **고침**: tap/scroll 샘플링 노브(`setSampleRate`), 월 파티션 권장 |
| 푸시 폭주 | 사용자당 통과 푸시 하루 12건 · 조용한 시간 · 30초 묶음 — 구현됨 |

## 4. 결정이 필요한 것

1. ~~**Apple 로그인**~~ → **결정됨**: 애플 로그인을 넣었다(iOS 는 네이티브 시트, 웹은 OAuth). 콘솔 등록 절차는 `docs/BROWSER-SETUP.md` 1절.
2. **답장 속도 하한**: 자전거(25) vs 세단(120). 낮을수록 가속 매출, 높을수록 왕복 완료율.
3. **무료 코인 상한 알림**: "오늘 무료 SC 를 다 모았어요" 알림을 넣을지.

## 5. 실기기에서만 확인되는 것
위치·알림 권한, 실제 Apple/Google/Kakao 로그인 창, 원격 푸시, 이미지 공유 시트, 스토어 결제, Supabase 실서비스 동기화(이 원격 환경은 supabase.co 접근이 막혀 있음 — CLAUDE.md 3절).

## 6. 디자인 전수 감사 (v5) — 이번 패스

### 6-2. 화면별 (사용성·완성도)

| 화면 | 발견 | 조치 |
|---|---|---|
| 홈 스토리 | 라벨이 전부 "어딘가"로 같아 무엇을 누르는지 알 수 없음 | 배달원 이름으로 바꾸고(국가는 열어야 공개, 규칙 유지) 거리·개수를 보조로. 본 스토리는 회색 링, 안 본 것은 그라데이션(인스타 I1) |
| 홈 하단 | CTA 옆 동그란 아이콘이 무슨 뜻인지 알 수 없음 | "지금 배달원 · 걷는 배달원 5 km/h" 한 줄 추가 |
| 홈 배너 | "매이(가) 머리 위를 지나가요" · 문구가 단어 중간에서 잘림 | 한국어 조사 헬퍼(`src/engine/korean.ts`)로 "매가"처럼 정확히, 보조 문구는 한 줄로 |
| 커뮤니티 | 거리 표기가 헤더와 엽서에 중복 · 더보기·북마크가 눌러도 아무 일 없음 | 중복 제거, 동작 없는 컨트롤 삭제, 피드 빈 상태와 로딩 스켈레톤 추가(인스타 I6) |
| 커뮤니티 스토리 | 보조 라벨이 전부 "하늘 위" | 배달원 속도(km/h)로 |
| 작성 | 잠긴 배달원 카드에서 "대여 40\nSC"로 줄바꿈 · 카드 높이 들쭉날쭉 · 헤더와 하단에 같은 CTA 2개 | 카드 높이 고정 + 문구 두 줄 분리, 헤더 CTA 제거(단계 표시만) |
| 상점 | 머리말이 "친구를 많이 만들거\n나"로 잘림 | 제목 짧게, 설명은 본문으로 |
| 프로필 | 비회원 화면에서 "가입"과 "플러스 시작"이 같은 무게로 경쟁 | 가입이 1차, 플랜은 2차(문구도 "플랜 보기") |
| 편지 목록·알림 | 빈 상태가 화면 위쪽에 붙어 여백이 크게 남음 | 남는 공간 가운데 정렬 + 아이콘을 면으로 |
| 설정 | "Expo Go 미지원(dev build)", "10km 격자" 같은 개발 용어가 사용자에게 노출 | 개발자 모드에서만 보이게 하고 평소에는 혜택 중심 문구 |
| 전체 | 스위치가 웹·iOS·안드로이드에서 제각각 | 공통 `Toggle` 컴포넌트로 통일 |

### 6-3. 막다른 길 · 흐름 버그

| 발견 | 조치 |
|---|---|
| **답장이 거절되면 그 편지에서 다시 답장할 수 없었다**(버튼이 사라짐). 친구가 되는 유일한 경로가 막힘 | 거절 상태에서 "다시 답장 쓰기" 복구 + 코인은 돌려주지 않는다는 안내 |
| **로그아웃이 온보딩까지 초기화**해 위치 선택부터 다시 해야 했고, 커뮤니티 봇 글까지 사라짐 | 내 데이터만 지우는 로그아웃(`signOutLocal`)으로 분리 — 위치·테마·투어 완료는 유지 |
| 자동 주행이 답장 거절(10%)에 걸리면 실패로 끝남 | 사용자가 하듯 다시 답장을 보내 이어가도록 시나리오 보강 |

### 6-4. 승인이 필요한 제안 (모션 · 구조)

`docs/DESIGN-AUTO.md` 의 트랙 B 라서 이번에 넣지 않았다.

1. **잡기 성공 순간 풀스크린 테이크오버 + 햅틱**(범프 B3) — 지금은 카드 전환.
2. **홈 하단 "내 편지" 카드를 3단 드래그 시트로**(범프 B2) — 속도·거리·가속을 한곳에.
3. **친구 핀 상태 점**(범프 B1) — 오는 편지 있음/답장 대기.
4. **플랜 3열 비교표**(인스타 I4) — 지금은 카드 나열.
5. **채팅 스와이프 답장**(인스타 I3).
