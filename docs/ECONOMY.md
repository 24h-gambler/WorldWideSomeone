# 경제 설계 계산 — 엿보기 · 끌어오기 · 즉시 친구의 한계와 층위

목표: **"친구를 많이 만들거나, 결제를 많이 하거나"** 두 길이 모두 살아 있으면서, 결제가 무료 유저의 재미(무작위 통과·잡기)를 망치지 않게 한도를 둔다.

## 1. 기준 지표 (무료 유저 1명 기준, 초기 밀도 가정)

| 지표 | 값 | 근거 |
|---|---|---|
| 하루 머리 위 통과 | 1.2건 | 도시 밀도 1만 MAU 기준 시뮬레이션(경로 폭 150km × 하루 발송량) |

## 2. 결제 기능의 "재미 훼손 한계" 계산

### 끌어오기(지나가는 편지를 나에게)
- 발신자 입장: 편지 1통이 통과하는 유저 수 ≈ 경로 길이 × 밀도 ≈ 평균 8명. 그중 결제 유저 비율 p, 끌어오기 사용률 u 라면 편지가 끌려갈 확률 ≈ 1−(1−p·u)^8.
- p=10%, u=50% → 34%. **1/3의 편지가 목적지에 못 가면 랜덤 목적지의 재미가 사라진다.** 허용선은 15% 이하 → p·u ≤ 2%.
- 따라서 한도: 편지당 끌어오기 **1회만**(한 번 끌려간 편지는 다시 못 끌어옴), 방어권 편지 불가, 개인 한도 플러스 **하루 1회**, 프로 **하루 3회**, 단건 구매 ₩1,900(코인 150). 이러면 u ≈ 10~15% → 끌림 확률 ≈ 8~11%로 안전권.
- 끌려간 편지의 발신자에겐 "누군가 끌어갔어요" 알림 + 방어권 구매 유도 → **방어권 수요 = 끌어오기 수요와 연동**(가격을 같은 급으로).

### 엿보기(내용 미리보기)
- 정보만 얻고 편지엔 영향 없음 → 재미 훼손 낮음. 다만 "엿본 뒤 끌어오기"가 결합되면 강력 → 엿보기는 싸게, 끌어오기는 비싸게.
- 한도: 무료 0, 플러스 **하루 3회**, 프로 **하루 10회**, 렌즈 5개 ₩1,900.

### 즉시 친구(커뮤니티에서 결제로)
- 게임 루프(편지 왕복)를 완전히 건너뜀 → 가장 비싸야 함. 무료 경로 친구 1명 ≈ ₩900의 **4배 이상** + 상대 수락 필수(강제 아님) + 하루 1회.
- 가격 **₩3,900**(코인 300). 상대가 거절하면 환불(코인 반환). 프로는 월 2회 포함.

### 바다 침수 구조
- 침수 = 3시간(실서비스) 정지 후 자동 부상, 주인이 즉시 건지려면 코인 50(≈₩600). 소액이라 결제 압박은 낮고 "들어와서 꺼내는" 재접속 동기.

## 4. 남용 방지 규칙(서버 검증)
1. 끌어오기: `letter.pulls == 0` && `!shield` && 대상이 통과 중(passby 활성)일 때만. 성공 시 `pulls=1`, 발신자 알림.
2. 엿보기: passby 활성 중에만, 같은 편지 재사용 무료.
3. 즉시 친구: 상대 수락 필요, 24h 내 미응답 시 환불. 같은 상대 재시도 7일 제한.
4. 모든 한도는 UTC 자정 리셋, `users/{uid}.quota{date, peeks, pulls, instant}` 에 기록.
